# APOBEC Histology Prediction

This repository contains the source code and out-of-fold (OOF) predictions for the study:
"Evaluating the Histological Predictability of APOBEC Mutagenesis after Adjustment for Tumor Mutational Burden".

## Contents
- `/data`: OOF prediction CSV files used for statistical analysis.
- `/scripts`: Python scripts for model training, evaluation, and survival analysis.
